# Research Purpose

## Core Goals
- Build a comprehensive knowledge base for all ADPV backend CRUD operations
- Document complete codebase structure, patterns, and relationships
- Create detailed implementation plans for all entity management (Users, Categories, Products, Suppliers, Orders, Clients)
- Establish standards for database schemas, business logic, stored procedures, and API patterns
- Develop testing strategies and automation scripts
- Enable AI-assisted development across the entire system

## Key Questions
- What is the existing client data model and relationships?
- How are clients currently handled in the frontend (Next.js) and backend (ASP.NET Core)?
- What naming conventions and patterns are used for tables, fields, and procedures?
- How to integrate client CRUD with PostgreSQL (pgvector) and Neo4j graph database?
- What security and authentication measures are required for client data operations?

## Research Scope
- Frontend: Next.js 16 + React 19, Tailwind CSS 4
- Backend: ASP.NET Core 10 with JWT authentication
- Database: PostgreSQL with pgvector, Neo4j (graph relationships)
- Focus: Complete CRUD operations for client management
- Deliverables: Implementation plan, code changes, tests, procedures
