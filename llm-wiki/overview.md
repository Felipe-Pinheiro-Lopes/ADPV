# Wiki Overview

## Project Context
The ADPV project implements a comprehensive client management system with CRUD operations. This wiki serves as the knowledge base for AI-assisted development, following the KaBe methodology for continuous knowledge accumulation.

## Architecture Overview
- **Frontend**: Next.js 16 + React 19, Tailwind CSS 4
- **Backend**: ASP.NET Core 10 with JWT authentication
- **Database**: PostgreSQL with pgvector + Neo4j for graph relationships
- **Testing**: Integrated test suites following project conventions

## Key Components
1. **Client Screen**: User interface for client data management
2. **API Controllers**: REST endpoints for CRUD operations
3. **Business Logic**: CaseBusiness classes handling domain logic
4. **Database Layer**: Tables, procedures, and graph relationships
5. **Testing Layer**: Unit tests, integration tests, and scripts

## Implementation Goals
- Complete client CRUD functionality
- Consistent naming conventions
- Proper error handling and validation
- Integration with existing authentication and security
- Comprehensive test coverage
